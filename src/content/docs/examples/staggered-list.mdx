The items of a list enter one after the other. One `Reveal` holds the items, and `stagger` animates its children. Use it for feature grids, key figures, changelogs, steps and search results.

<Example useCase="stagger" />

## Why one `Reveal` for the whole list

One `Reveal` for the whole list creates one observer and keeps one copy of the options. A `Reveal` around each item creates an observer for each item, and the items reveal at different times as the user scrolls.

With `stagger`, the children reveal together as the list enters the viewport. If the list is long, the last items can start their animation below the fold. Split the list into groups, or give each group its own `Reveal`, as in [Alternating sections](/examples/alternating-sections/).

## Tips

- `stagger: 0` animates all the children together.
- Choose `stagger` between 40 and 120 ms for lists. A larger value makes a long list slow to finish.
- Use `pop()` for key figures. Each figure grows past its resting size, then settles back.
- The library reads the children when the list is revealed. Items that you add before the reveal animate. Items that you add later do not.
- `stagger` animates child elements only. Put text in an element, as in [Text animation](/examples/text-animation/).
- In React, always render the children. See [`useReveal`](/react/#the-usereveal-hook) for the rules with a hook.
