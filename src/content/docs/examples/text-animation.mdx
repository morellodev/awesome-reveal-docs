## Keep the text accessible

Split text is a problem for screen readers: they can read each word or letter as a separate item. The code prevents this in two steps:

1. The full title is in an element that only screen readers see. `visually-hidden` is a class in `styles.css`. It hides the element visually, but keeps it for assistive technology.
2. The animated copy has `aria-hidden`.

Then screen readers read the title one time, and find-in-page finds the full title.

## Tips

- Choose `stagger` between 20 and 40 ms for letters, and between 40 and 80 ms for words. A long text with a large value is slow to finish.
- Use a short `duration` for letters, for example `400`.
- Use `fade()` or a small `slide({ distance: 12 })`. Large movements of many small elements look noisy.
- With `once: false`, the text hides and plays again at each entry. See [Viewport options](/concepts/options/#viewport).
