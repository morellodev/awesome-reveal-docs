## Wipe and circle

`wipe` and `circle` are custom keyframes: arrays that animate `clip-path`. The code puts each array in a constant next to the imports, so the markup stays short.

End the keyframes at a shape that shows the whole image, such as `inset(0)`. Do not end them at `{}`. `clip-path` interpolates only between basic shapes, and its resting value `none` is not a basic shape. With `{}`, the image appears at once halfway through the animation.

`blur`, `wipe` and `circle` repaint the image on each frame in some engines. On a large image, test them on a slow device. If the animation stutters, use `scale` or `fade`.
