`@awesome-reveal/react` hides an element until it enters the viewport, and then animates it. It needs React 18 or later.

## Install

  </TabItem>

## Reveal an element

Put the content in a `Reveal` component:

```jsx
import { Reveal } from "@awesome-reveal/react";

<Reveal>
  <p>I gently appear as I enter the viewport</p>
</Reveal>;
```

`Reveal` renders a `div` around its children. With no `keyframes`, the `div` fades in and moves up.

## Choose an animation

Import a keyframes factory from `@awesome-reveal/react/keyframes`, and give its result to `keyframes`:

```jsx
import { Reveal } from "@awesome-reveal/react";
import { slide } from "@awesome-reveal/react/keyframes";

<Reveal as="section" keyframes={slide({ direction: "left" })} duration={800}>
  …
</Reveal>;
```

- `as` sets the tag of the rendered element. `Reveal` gives its other props and its `ref` to that element.
- `slide({ direction: "left" })` moves the element to the left as it fades in.
- `duration` is in milliseconds. The default is `600`.

The other factories are `fade()`, `scale()`, `blur()`, `pop()` and `enter()`.

## Animate your own element

To animate your own element or component with no wrapper, use the `useReveal` hook. Attach `ref` to the element, and spread `style` last into its style:

```tsx
import { useReveal } from "@awesome-reveal/react";
import { fade } from "@awesome-reveal/react/keyframes";

function Card() {
  const { ref, style, revealed } = useReveal({
    keyframes: fade(),
    threshold: 0.3,
  });
  return (
    <article
      ref={ref}
      style={{ padding: 16, ...style }}
      data-reveal={revealed ? undefined : "hidden"}
    >
      …
    </article>
  );
}
```

`style` hides the element until the reveal. `threshold: 0.3` reveals the element when 30% of it is visible.
