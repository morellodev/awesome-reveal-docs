awesome-reveal hides an element until it enters the viewport, and then animates it. Each framework has its own package. Choose your framework in the tabs below.

## Install

<Tabs syncKey="framework">
  <TabItem label="React" icon="seti:react">
    <Code code="pnpm add @awesome-reveal/react" lang="shell" />
    The package needs React 18 or later.
  </TabItem>
  <TabItem label="Vue" icon="seti:vue">
    <Code code="pnpm add @awesome-reveal/vue" lang="shell" />
    The package needs Vue 3.5 or later.
  </TabItem>
  <TabItem label="Astro" icon="astro">
    <Code code="pnpm add @awesome-reveal/astro" lang="shell" />
    The package needs Astro 6 or 7.
  </TabItem>
</Tabs>

<Aside>
  Version 1.0 is a prerelease. Until 1.0.0, the `latest` tag installs the newest
  prerelease.
</Aside>

## Reveal an element

<Tabs syncKey="framework">
  <TabItem label="React" icon="seti:react">
    Put the content in a `Reveal` component:

    <Code code={reactReveal} lang="jsx" />

    `Reveal` renders a `div` around its children. With no `keyframes`, the `div` fades in and moves up.

  </TabItem>
  <TabItem label="Vue" icon="seti:vue">
    Put the `v-reveal` directive on the element:

    <Code code={vueReveal} lang="vue" />

    With no `keyframes`, the element fades in and moves up.

  </TabItem>
  <TabItem label="Astro" icon="astro">
    Put the content in a `Reveal` component:

    <Code code={astroReveal} lang="astro" />

    `Reveal` renders a `div` around its children. With no `keyframes`, the `div` fades in and moves up.

  </TabItem>
</Tabs>

## Choose an animation

Each package has a `keyframes` entry point with the same keyframes factories. Give the result of a factory to the `keyframes` option:

<Tabs syncKey="framework">
  <TabItem label="React" icon="seti:react">
    <Code code={reactChooseAnimation} lang="jsx" />

    - `as` sets the tag of the rendered element. `Reveal` gives its other props and its `ref` to that element.
    - `slide({ direction: "left" })` moves the element to the left as it fades in.
    - `duration` is in milliseconds. The default is `600`.

  </TabItem>
  <TabItem label="Vue" icon="seti:vue">
    <Code code={vueChooseAnimation} lang="vue" />

    - The value of `v-reveal` is an object with the options.
    - `slide({ direction: "left" })` moves the element to the left as it fades in.
    - `duration` is in milliseconds. The default is `600`.

  </TabItem>
  <TabItem label="Astro" icon="astro">
    <Code code={astroChooseAnimation} lang="astro" />

    - `as` sets the tag of the rendered element. `Reveal` gives its other attributes to that element.
    - `slide({ direction: "left" })` moves the element to the left as it fades in. The factory runs on the server.
    - `duration` is in milliseconds. The default is `600`.

  </TabItem>
</Tabs>

The other factories are `fade()`, `scale()`, `blur()`, `pop()` and `enter()`. See [Keyframes](/concepts/keyframes/).

## Animate your own element

<Tabs syncKey="framework">
  <TabItem label="React" icon="seti:react">
    To animate your own element or component with no wrapper, use the `useReveal` hook:

    1. Attach `ref` to the element.
    2. Spread `style` last into the element style.

    <Code code={reactUseReveal} lang="jsx" />

    `style` hides the element until the reveal. `threshold: 0.3` reveals the element when 30% of it is visible.

  </TabItem>
  <TabItem label="Vue" icon="seti:vue">
    `v-reveal` already animates your own element, with no wrapper. On a component, it animates the root element of the component.

    To render the element from a component instead, use `Reveal`:

    <Code code={vueRevealComponent} lang="vue" />

    `threshold: 0.3` reveals the element when 30% of it is visible.

  </TabItem>
  <TabItem label="Astro" icon="astro">
    Astro has no hook or directive. `Reveal` renders the element: set the tag with `as`, and give your attributes to `Reveal`. See [Astro](/astro/).

  </TabItem>
</Tabs>
