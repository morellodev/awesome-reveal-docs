## Reveal anything in a few lines of code

Wrap any element in `Reveal`. It animates as soon as it scrolls into view, with no CSS to write and no layout shift.

```jsx
import { Reveal } from "@awesome-reveal/react";
import { slide } from "@awesome-reveal/react/keyframes";

<Reveal keyframes={slide({ direction: "left" })}>
  <p>I gently appear as I enter the viewport</p>
</Reveal>;
```
