## Reveal anything in a few lines of code

Wrap an element in `Reveal`, put `v-reveal` on it, or call `reveal()`. It animates as soon as it scrolls into view, with no CSS to write for the animation and no layout shift.

<Tabs syncKey="framework">
  <TabItem label="React" icon="seti:react">
    <Code code={reactReveal} lang="jsx" />
  </TabItem>
  <TabItem label="Vue" icon="seti:vue">
    <Code code={vueReveal} lang="vue" />
  </TabItem>
  <TabItem label="Astro" icon="astro">
    <Code code={astroReveal} lang="astro" />
  </TabItem>
  <TabItem label="JavaScript" icon="seti:javascript">
    <Code code={jsReveal} lang="js" />
  </TabItem>
</Tabs>

By default, the element fades in and slides up. To use [another animation](/concepts/keyframes/), set one option.

## Why Awesome Reveal

<FeatureGrid>
  <FeatureCard color="orange" title="Tiny and dependency-free" icon="feather">
    About 2 kB gzipped for `Reveal` with one animation, with zero third-party
    dependencies. Tree-shaking keeps only the animations that you import.
  </FeatureCard>
  <FeatureCard color="orange" title="Smooth, native performance" icon="zap">
    Intersection Observer detects the reveal, with no scroll listeners. The Web
    Animations API runs it on the compositor where possible.
  </FeatureCard>
  <FeatureCard
    color="green"
    title="Works in every major browser"
    icon="app-window"
  >
    Built on [Baseline Widely available](/concepts/browser-support/) web APIs
    that Chrome, Edge, Firefox and Safari have supported for years.
  </FeatureCard>
  <FeatureCard
    color="green"
    title="Accessible by default"
    icon="person-standing"
  >
    Respects `prefers-reduced-motion` out of the box. Hidden content stays in
    the accessibility tree and in find-in-page.
  </FeatureCard>
  <FeatureCard
    color="blue"
    title="Server rendering with no flash"
    icon="server"
  >
    React, Vue and Astro render content hidden on the server, so it never
    flashes before the animation. Create keyframes in React Server Components or
    in the Astro frontmatter.
  </FeatureCard>
  <FeatureCard color="blue" title="Built for TypeScript" icon="seti:typescript">
    Strict types for every option, element and keyframe, with full autocomplete
    in your editor.
  </FeatureCard>
  <FeatureCard color="purple" title="Custom animations" icon="spline">
    Six built-in animations, spring easing, and custom keyframes from any
    function of time. See [Keyframes](/concepts/keyframes/).
  </FeatureCard>
  <FeatureCard color="purple" title="Ready for AI coding agents" icon="bot">
    The packages ship [agent skills](/agent-skills/), so Claude Code, Cursor and
    other agents add animations and migrate v4 code the right way.
  </FeatureCard>
</FeatureGrid>
