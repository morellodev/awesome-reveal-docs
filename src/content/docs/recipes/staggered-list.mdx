To make list items enter one after the other, set `stagger` on the element that holds them. The element reveals as one unit. Then each child starts `stagger` milliseconds after the previous one.

## Why one `Reveal` is better than one for each item

One `Reveal` for the whole list creates one observer and keeps one copy of the options. A `Reveal` around each item creates an observer for each item, and the items reveal at different times as the user scrolls.

With `stagger`, the children reveal together as the list enters the viewport. If the list is long, the last items can start their animation below the fold. Split the list into groups.

## Tips

- `stagger: 0` animates all the children together.
- Choose `stagger` between 40 and 120 ms for lists. A larger value makes a long list slow to finish.
- The library reads the children when the list is revealed. Items that you add before the reveal animate. Items that you add later do not.
- `stagger` animates child elements only. Put text in an element, as in [Animate text on scroll](/recipes/text-animation/).
- In React, always render the children. See [`useReveal`](/react/#the-usereveal-hook) for the rules with a hook.
